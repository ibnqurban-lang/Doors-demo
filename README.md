# LoftCalc — калькулятор Loft-перегородок и алюминиевых дверей

Демо-приложение: профессиональный калькулятор для расчёта стоимости алюминиевых
Loft-перегородок и дверей с визуальным 2D/3D-конфигуратором.

## Возможности

- **Главный экран / база проектов** — создание заказа (клиент, телефон, адрес,
  дизайнер, дата, № заказа), поиск по клиенту/телефону/номеру/адресу/дате.
- **Визуальный конфигуратор** — три колонки: параметры изделия слева, 2D-схема
  или интерактивная 3D-модель по центру, расчёт стоимости и спецификация справа.
  Любое изменение параметров мгновенно перестраивает схему/модель и расчёт.
- **10 типов изделий**: Loft-перегородка, распашная/раздвижная дверь (одно- и
  двустворчатые), перегородка с дверью, фрамуга, угловая и П-образная
  конструкции, индивидуальная конструкция.
- **3D-сцена** (react-three-fiber): вращение, зум, виды спереди/сбоку/сверху/под
  углом, анимация открывания-закрывания распашных и раздвижных полотен,
  технический режим и режим «Показать в интерьере» (гостиная, кухня, офис,
  переговорная, спальня, гардеробная), снимок вида в PNG.
- **Автоматический расчёт**: длины и количество профилей, раскрой на
  6-метровые хлысты (оптимизация с учётом пропила и отходов), площадь и
  количество стекла, подбор фурнитуры по типу открывания, стоимость покраски,
  себестоимость, наценка, итоговая цена, прибыль и маржинальность.
- **Спецификация материалов** с экспортом в CSV (Excel) и печатью.
- **Коммерческое предложение** — печатная форма с логотипом, данными клиента,
  эскизом/фото изделия, спецификацией, ценой, условиями оплаты, сроками и
  гарантией; экспорт в PDF (печать) и Excel (CSV).
- **Настройки администратора** — редактируемые без участия программиста
  справочники: профили (14 типов), профильные системы, стекло (10 видов ×
  4 толщины), фурнитура (16 категорий), покраска и RAL-цвета, услуги
  (монтаж/доставка/подъём/демонтаж/замер/выезд), материалы, наценки (по
  статьям или фиксированная сумма) и формулы расчёта (длина хлыста, потери на
  пропил, нормативы отходов и запаса, пороги усиления профиля и т. д.).
  Экспорт/импорт всей базы в JSON, сброс к заводским значениям.

Ничего не «зашито» в код: все цены, нормы расхода и коэффициенты хранятся как
данные (zustand + localStorage) и правятся через Admin-экраны — калькулятор
пересчитывается автоматически.

## Стек

React 19 + TypeScript + Vite, Tailwind CSS v4, react-router-dom, zustand,
three.js / @react-three/fiber / @react-three/drei.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

npm run build
